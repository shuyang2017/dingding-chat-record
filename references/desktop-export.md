# macOS 钉钉归档实测

以下来自两个群的实际归档，描述可用路径和已观察到的问题，不是固定索引、坐标、群标识或版本保证。以当前 cua_repl 文档和新观察为准。

## 文件与图片

1. 首次调用按工具要求只执行一个入口，如 `var ding = await cua.getApp("com.alibaba.DingTalkMac")`。上下文压缩后恢复工具文档；运行时重置后重新绑定。
2. 搜索完整群名并核对标题。顶部文件夹图标曾打开群文件侧栏，聊天记录图标曾打开独立历史窗口。无标签时用截图定位，切换后再取 AX，不沿用另一窗口的索引或坐标。
3. 文件列表表头复选框曾支持全选，随后出现“已选 N 项”和“下载”。记录数量并检查是否继续滚动加载；全选不一定包含未加载项。遇到无权或不支持下载的提示，记录具体名称，继续保存其余项。
4. 批量下载可能打开名为“打开”的文件夹选择器，实际在选择保存位置。用 `super+shift+g`，根据新 AX 的 PathTextField 设置目标目录，Return 后核对“位置”，再点“确定”。下载器可能创建日期加文件名的子目录，保留层级。
5. 图片及视频页点“选择”后可能暴露已加载项的复选框。实测每批最多15项，达到限制后余项变灰；按当前限制分批继续。下载后选择状态可能自动清空，重新观察再选下一批。
6. 在线文档链接可能在外部浏览器打开，钉钉 AX 无变化不表示失败。检查浏览器实际页面。文档菜单“下载到本地”有时支持 Word/Markdown/PDF，有时为灰色，逐项判断权限。只使用可用导出，核验导出确认与下载完成。

## 搜索与正文互补

- 聊天记录窗口曾在搜索框为空时自动列出最新消息，向下滚动加载更早记录。获取完整 AX，保存每批观测；仅截取任务相关聊天区，避免保存其他会话侧栏。
- 列表虚拟化会移除早期节点。每批均采集，保留相邻批可验证的重叠，不只保存最后一屏。显示“请稍候”时观察加载结果；进度不动时看截图，区分最早边界、加载失败和滚动区域错误。
- 长消息实测会截断，末尾不一定有省略号；长度与标点不能证明完整。正文还含搜索不展示的建群、改名、撤回和日程卡片。补采正文后按作者、日期与内容锚点关联长消息；引用结构不明时保留原始块。
- 正文按屏滚动并保留重叠。滚动条设为1或大幅滚动有时只到已加载片段底部；必须核对实际日期及消息，不能把控件值当作已到最新的证据。
- “今天/昨天”按采集时本地日期解释，保留原始显示值。正文时间标签稀疏，不为每条补造时间。AX 的未知占位可能是真实 @，历史列表或截图可补出姓名。头像签名不属于发言。
- 内容可见但 AX 只剩空 HTML 容器时，截图确认。曾通过关闭该历史窗、从目标群重新打开恢复；使用截止日期从断点前重叠续读。不要反复查询同一空树。

## 落盘与断点

优先使用当前工具允许的保存观测或下载能力。只有已显示或授权取得的材料才进入文件处理，不为保存文本寻找客户端内部接口。

实测备用路径是用文本编辑器落盘已观察数据：

1. UI 工具持久变量保存相关 AX 文本并组成 JSON，必要时做纯数据压缩与 Base64 编码以降低粘贴体积；编码不是额外数据来源。
2. 新建 TextEdit 文档并确认纯文本，粘贴结果，通过保存对话框写入本次归档目录。使用新文档，避免覆盖用户已有或另一群归档。
3. 文件工具读取刚保存的文本、解码为 JSON，验证批数、首尾与内容，再生成阅读版。编码传输包移入原始采集目录，不把 Base64 当作阅读版交付。

每批循环保持短小，使用支持的超时，留出状态读取和进度沟通时间。过长循环曾导致运行时重置、变量丢失，故定期保存断点，不只依赖内存。断点包含群标识、采集时间、方向、最后消息锚点、已保存批号及附件状态，不保存凭证。
