# 归档质量与交付

## 建议产物

```text
<群名>/
  聊天记录/
    聊天记录.txt
    聊天记录.html          可选阅读版
    聊天记录.json          或CSV
    正文补充记录.txt
    原始采集/              批次快照与断点
  上传文件/                保留名称和层级
  附件清单.csv
  群消息中的文档链接.txt    有链接时生成
  归档说明.md
```

阅读版每条保留作者、界面时间、正文、引用关系及附件/卡片占位；额外补录注明依据。原始材料与补齐文本分开，保留来源批号。作者、时间、卡片或图片关系不明时标记未知，不凭业务上下文补写。

## 计数与批次对齐

优先保留连接器或 UI 实际提供的稳定消息标识。没有标识时，按相邻批顺序和连续重叠片段对齐，保留单批内重复发言。仅凭作者、分钟和正文全局去重会误删同一分钟内两次相同的真实发言，不能作为默认算法。

无法判定重叠还是独立发言时保留两份，标注疑似重叠。显示采集条目数或已对齐记录数及计算方式，不包装为钉钉官方消息总数。正文补充页允许重叠；页面块数、系统提示数与发言条数分开。

补齐长消息前核对作者、时间与连续内容锚点；引用段不属于当前发言。保留搜索文本及正文来源，不通过模糊前缀匹配静默替换其他消息。检查超长消息、富文本、链接及系统事件后生成最终阅读版。

## 验收

- 范围：保留最新和最早边界的原始观测，优先以建群提示或明确无更早记录证明起点。滚动无变化不足以证明完整，须检查加载状态、相邻批覆盖；中途空段列明日期或锚点。
- 附件：逐项对照列表和落盘路径，文件夹核对子项；检查名称、大小与下载完成状态。服务端仅显示近似大小时如实标注。记录 SHA256；压缩包可做完整性检查，不执行内容。文件移动后重建清单。
- 媒体：面板分批计数与实际文件核对。注明客户端给出的压缩/缩略版本，不把成功下载写成原图备份；映射不明时不声称逐条关联。
- 链接：区分上传文件、在线文档快捷方式与外部链接，保存来源、导出格式、状态和受限原因。普通外部链接保留链接；用户要求链接文档正文时再逐篇读取导出。下载或打印灰色时报告限制，不绕过权限。
- 交付：从实际文件重建统计与清单，检查文本可读、结构化记录可解析及压缩包完整。归档说明记录当前账号可见范围、不可恢复的撤回/删除内容、富文本限制及未保存项，不能声称可导入恢复。

多个群分别归档；补采记录本次范围与版本，不混入另一群或旧本地同名文件。
